# 🛡️ Web Security Tester

Open the HTML file in any browser to test website security vulnerabilities.

## 🔧 **Features:**
- Test CORS vulnerabilities
- Check Clickjacking protection  
- Analyze security headers
- Verify HTTPS enforcement

## 🚀 **Usage:**
1. Save the code as `index.html`
2. Open in Chrome/Firefox
3. Enter website URL to test
4. Click test buttons

## ⚠️ **Important:**
- Test only websites you own
- All processing is local
- Use for security education only

**Files:** Just 1 HTML file
